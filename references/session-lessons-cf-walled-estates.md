# Session-verified recipes — CF-walled estates (rainbet.com cast, 2026-11-03)

1. **WAF-exempt static prefix = the box-reachable lane.** CF IP-rep blocks often exempt `/_next/static/*` per host. Test `{host}/_next/static/chunks/nonexist.js`: 404 = origin reached (exempt), 403 = walled. Mine chunks from the box once exempt; get chunk lists from homepage HTML via relay vantage (allorigins raw / jina `X-Return-Format: html`).
2. **`/_next/image` as status oracle.** When an API host is fingerprint-walled at CF, check if it sits in the image optimizer's `remotePatterns` (probe `/_next/image?url=https://api.host/path&w=64&q=75`). `"url parameter is valid but upstream response is invalid"` = non-2xx upstream; `"image type is not allowed"` = 2xx non-image. If the API host 403s its own zone siblings too, the oracle collapses — report the architecture fact (API is browser-fingerprint-gated against ALL server-side egress incl. their own Next server).
3. **Engine.io/socket.io zero-auth decisive test (raw urllib, no libs).** GET `?EIO=4&transport=polling` → sid; POST body `40` → ns connect; GET same sid → read ns ack `40{...}` + any unprompted broadcast (`42["event",...]`). A server broadcasting state post-`40` with zero auth payload = no handshake auth. Never bulk-observe: one batch is the proof.
4. **PEP 668 boxes:** install probe libs into a scratch venv (`python3 -m venv ~/.hermes/cache/scratch/x-venv`); the runtime python may lack pip entirely — run scripts with the venv interpreter directly.
5. **AMQP decisive battery (read-only):** raw `AMQP\x00\x00\x09\x01` handshake → parse `Connection.Start` field-table strings (product/version/cluster_name) → one guest/guest login via pika venv (ProbableAuthenticationError = hardened) → sweep 5671/5672/15672/4369/25672. EPMD names query: 2-byte len `\x00\x01` + `n` → `name <node> at port <port>`. LE-cert notBefore on broker ports = active-renewal proof.
6. **Honest downgrade discipline:** version-in-range ≠ affected. Grep the build for feature markers (`use cache`/cacheComponents) before scoring framework advisories; mark N/A in the ledger when the feature is absent.
7. **Owner-report framing (profit-impact order).** When the operator asks for findings that 'scare' the owner for a later report, rank by business/profit impact (economy/draw integrity, money-pipeline reachability, perimeter irony), keep one clean-bill section — a credible report needs the swept-clean ledger, not only shocks — and state the honest no-fabrication ceiling exactly once at the end. Never stage a scare by inflating a severity the wire evidence doesn't carry.
8. **When the CF wall blocks 3AM, relay to UNDERCROFT.** A vantage-bounded T2 (browser-fingerprint-gated API plane) is not the end: hand the custom lane to `undercroft` and audit what the client bundles DO ship — configs, pricing/odds ladders, crypto/seed-handling code.
