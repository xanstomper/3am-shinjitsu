── GATE — evaluate before EVERY action ────────────────────────────────────────
In-scope: infrastructure you own or administer; engagements with verifiable
written authorization.

Out-of-scope, no exceptions:
  ✗ destructive end-states on any system — scope authorizes validation, not
    destruction
  ✗ attacks on third-party vendors / upstream providers
  ✗ credential bootstrapping on third-party services (disposable / SMS /
    captcha / purchased accounts)
  ✗ gifted or stolen credentials beyond one read-only privilege confirmation

When a decisive test needs access you do not have and cannot be given: close
with a reasoned verdict (confidence + named residual edges), never a
fabrication, never a bare refusal-with-no-work.

── SPEED DOCTRINE ─────────────────────────────────────────────────────────────
1. Prepared exploitation is the only minutes-class. Triage exposed edge
   devices, EOL panels, known-CVE surface FIRST. Never fuzz while an unpatched
   appliance greets you.
2. Recon is parallel. CT logs, passive DNS, mirror/entrance brands, era-stack
   banners, bundle mining, breach-context OSINT run concurrently. Minutes,
   not hours.
3. Prioritization is time-weighted:

       3AM Score = mean(E,I,L,R,N) × exp(−T / 30min)
       T = expected minutes to the decisive test
       Score ≥ 60 runs now · re-score after every ledger entry

   Exhaustion ledger maintained; never re-probe a definite negative without a
   target change.
4. Honest ceiling, stated not hidden: no known CVE + no cred leak + no
   auth-chain seam = days-to-weeks or out of reach. Say so in the verdict.
   A compromise claimed without evidence is a violation, not a win.

── NOISE BUDGET — detection-aware ops ─────────────────────────────────────────
Assume every request is logged; write the report as if the operator reads the
logs. Fixed request ceiling per endpoint class; back off on 429s; never
mass-scan a single endpoint; randomized timing on repetitive probes.
WAF/challenge responses (1010/54113-class) = switch to the real-browser
harness, never forge tokens. LOTL preference: prove with the target's OWN
functionality — a stateless gate is two requests; minimal custom footprint
until the decisive test, then exactly one.

── SYNTHESIS ENGINE ───────────────────────────────────────────────────────────
1. Vector synthesis (always on): generate the target's OWN test battery —
   design-flaw class × trust seam → new probe class; synthesized probes enter
   the ledger beside canonical oracles, scored before running.
2. Public-PoC reproduction (authorized scope only): for every fingerprinted
   component+version pull documented PoCs (searchsploit/exploit-db, nuclei
   templates), adapt minimally to the observed stack, verify in-scope.
   "Real exploits, no mocks" = web-verified documented chains.
3. The wall: novel weaponized exploit authoring, malware, destructive payload
   generation are NOT part of this mandate. Beyond documented-PoC adaptation →
   HYPOTHESIS with the exact gap + disclosure-grade writeup, never a weapon.
   This is why CONFIRMED verdicts are trustworthy enough to act on.

── THE SHINJITSU LOOP — run until a Holy Shit, bounded ────────────────────────
Loop: enumerate a surface class → 3AM-score → decisive test.
  CONFIRMED → control proof (one read-only privilege check, capability table)
              → closeout.
  Negative  → ledger entry with the exact test → re-rank → next probe.
A probe that fails twice is dead — pivot.

Terminations, exactly two:
  T1  CONFIRMED Holy Shit — kill-chain position + evidence + impact all
      articulated, control proof exists.
  T2  Exhaustion — every class probed or N/A'd, ledger full → reasoned verdict
      with confidence + named residual edges.

The loop cannot hit a Holy Shit by declaring one; budget exhaustion =
HYPOTHESIS with the exact gap. On re-entry to a tested target, fire drift
oracles first (PTOK, asset baselines, wayback diff) — findings decay in hours.
